How it works

The same idea that DeepMind's FermiNet and other neural quantum state methods use for atoms and molecules, built from scratch for one dimension.

1 · Energy is the loss

For any trial wavefunction, the Rayleigh quotient is an upper bound on the true ground-state energy. Pushing it down drives the network toward the ground state. No labelled data is involved.

E[ψ] = (½∫ψ′² dx + ∫Vψ² dx) / ∫ψ² dx ≥ E₀

2 · Excited states by deflation

Each higher state is projected onto the space orthogonal to the states below it (Gram–Schmidt), then its energy is minimised there. Gradients flow through the projection, so orthogonality holds exactly, with no penalty weight to tune.

φₙ = χₙ − Σj<n ⟨ψ̂ⱼ|χₙ⟩ ψ̂ⱼ

3 · Boundary conditions built in

The particle lives in a box of half-width L = 6. Multiplying the network by an envelope makes ψ vanish at the walls for every set of weights, so the optimiser never has to learn it.

χₙ(x) = (1 − x²/L²) · Nₙ(x),  Nₙ: 1→32→32→1 tanh

Engineering

No ML libraries and no build step. Small modules with one job each, all covered by the test suite.

src/engine.jsAutodiff for scalar-input MLPs: Taylor-mode forward pass returning ψ and ψ′, hand-derived reverse pass, Adam.
src/solver.jsVariational solver: envelope, quadrature, Rayleigh quotient, Gram–Schmidt deflation and its gradient.
src/eigensolver.jsExact reference: finite-difference Hamiltonian, Sturm-sequence bisection, inverse iteration, Richardson extrapolation.
src/trainer.jsOne training run: schedule, history and plain-data snapshots.
src/worker.jsRuns the trainer on a background thread. Falls back to the main thread automatically.
src/potentials.jsPreset potentials and user-drawn ones.
tests/12 tests: gradient checks, three analytic spectra, orthonormality, residuals, variational bound, a training integration test.
  • First-order Taylor mode instead of nested autodiffIntegrating the kinetic energy by parts means only ψ′ is needed. One forward pass returns it.
  • Activations cached per quadrature pointEvery forward pass runs once per step. The backward pass reuses the cache.
  • A reference you can trustSturm bisection finds the k-th eigenvalue directly. Richardson extrapolation cancels the O(h²) error, giving about 10⁻⁸ accuracy on the harmonic oscillator.
  • Stale results can't leakEach run carries a generation number. Snapshots from a superseded run are dropped.
